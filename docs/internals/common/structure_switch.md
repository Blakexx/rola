# `common/structure_switch.cuh` — the structure switch as one primitive

Mirrors `csrc/rola/src/common/structure_switch.cuh`.

Constitution R9 permits a CTA-uniform branch on STRUCTURE — a tile count, a mode, an arm
axis — and forbids one on a measured statistic. The enforcement addendum (Blake,
2026-08-29) names four layers every such branch owes. They are a contract on the pair
(generated set, switch), not on the switch alone, and this page states which layer lives
where so a reviewer can check all four at one reading.

## The four layers, and who owns each

1. **The cases are GENERATED, with a static_assert on the count.** The set is a
   `constexpr` enumeration derived from the arm's own shape — never a hand-written list.
   `uniform_switch<NA>` takes that count as its template argument and refuses an empty
   set; the caller asserts its own bound.
2. **A compile-time exhaustiveness assert**: the derivation's possible outputs are a
   subset of the covered set. For a set generated BY the derivation this is a property of
   the generator and is asserted as such: a shape that is not a member comes back as a
   refusal with its own words, never as an index.
3. **A launch-time refusal at the seam, naming the uncovered case.** The dispatch reads
   the SAME enumeration the bodies compiled against and refuses by name before any launch.
4. **A trapping default and a post-build coverage sweep.** `uniform_switch`'s miss path
   is `__trap()`, never a fallthrough, and the set's coverage is swept per built arm.

<a id="uniform-switch"></a>
## `uniform_switch`

`uniform_switch<NA>(value, body)` instantiates `body(std::integral_constant<int, a>)` for
every `a < NA` and executes exactly the one whose index equals `value`. The instantiation
is what makes the member's spans and shifts immediates; the branch is uniform, so no lane
diverges and nothing is predicated.

THE DISPATCH IS INLINE BY CONSTRUCTION: a chain of force-inlined frames (`detail::uniform_switch_from`), one a
member, with no lambda of its own, and a body large enough to pass the inliner's threshold carries
`__attribute__((always_inline))` on its lambda. A lambda's call operator is not force-inlined, so a large one is
outlined into a call -- its references in memory, and in an outlined body ptxas proves no shuffle or vote converged,
so each one falls back to a convergence subroutine (the producer's solve: 400-1,000 calls, a 500-byte frame).

`value` must be a launch-derived structural index — a field of the addressing block, an
arm axis — and never a per-lane or data-dependent quantity. That is R9 itself, and the
primitive cannot check it; a reviewer reads the call site.

The set is walked by recursion, not by `common/static_for.cuh`'s `static_for`: a loop over a lambda is the lambda this
primitive must not have.

## Placement is a cost, and it is the caller's

The body is instantiated `NA` times AT EACH CALL SITE. A switch inside a loop that the
schedule enters many times per launch costs code, not branches; a switch enclosing a whole
phase costs one branch per phase and duplicates the phase. Code size
becomes an I-cache stall class, and hoisting the switch to the phase merges the members'
live ranges and spills — so the placement is stated and MEASURED per user rather than
left to habit.

## A new in-kernel switch answers seven questions

Blake, 2026-08-29: "let's get this done the right way and pay the cost we need to pay, and remember these lessons for
the future as we build more in-kernel switches." Each failed switch was shape misfiled as addressing, or a switch put
in the wrong place; a switch is justified by coverage at additive cost, not by speed or compile time.
1. Is the quantity SHAPE (which register holds which element in an unrolled loop) or ADDRESSING? Shape is compile-time
   or a `uniform_switch` over a generated set, never a runtime operand (a runtime shape doubled the instructions).
2. The set is enumerated from the inputs (`constexpr`), deduplicated, count- and exhaustiveness-asserted; never a
   hand-written table.
3. The switch sits OUTSIDE the hot loop, one specialized body a member: inside it, the members' live ranges merge
   (900 B of spills at `D >= 3`) and their code interleaves (5.9x the I-cache footprint).
4. One source -- a template and inlined helpers -- compiled to N bodies; the duplication is accepted (only the
   selected body is hot), and no `__noinline__` helper sits in a hot loop.
5. A per-side or per-phase choice is device-side and additive; a whole-kernel choice is a template axis
   (`arm_switch`); the two are never multiplied.
6. A switch that changes an ownership partition states a SELECTIVITY line and a BANK-BEHAVIOUR line beside its
   instruction floor (a form met every per-instruction floor and lost 40%; another ran 2.7x the conflicts).
7. The compile is budgeted: members x phases an arm, the long-pole arm, a TU a member as the lever.
