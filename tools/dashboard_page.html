Carry kernel dashboard

Every stored measurement of the carry kernel and its variants over the cells. tools/dashboard.py renders it from the ledger reports and the probe record, and measures nothing: the same inputs give the same page.

Standings

Each cell's newest stored value per measurement, from the build ledger. Time is against the baseline in the same interleaved session; cycles are a warp a CTA-window.

Variants over the cells

Every probed binary, one row per binary and stage, its median launch time over the baseline measured in the same interleaved session (the newest session per cell). Below 1 is faster (blue), above 1 slower (orange). A dashed value carries a flag, such as a baseline run off its order policy; hover a value for the milliseconds and flags.

Pipe timelines

Composer

Each rung makes one more part of a phase real, the rest stubbed. The step is what that part adds to the phase's cycles a warp a window.

Builds

Every build ledger report in order. The charts plot total cycles a warp a CTA-window per cell.
